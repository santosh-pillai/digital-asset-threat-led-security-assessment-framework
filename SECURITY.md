# Security and Responsible Disclosure

This repository contains a security assessment framework, not a managed product or service.

Do not publish credentials, private keys, customer data, confidential reports or exploit details that could create risk for a real organization.

For sensitive issues involving this repository's materials, contact the maintainer through the contact options on:

https://santoshpillai.com

For vulnerability reports concerning third-party products or organizations, use the relevant vendor's or organization's security disclosure process.
