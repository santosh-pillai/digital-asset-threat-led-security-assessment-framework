**Professional designation:** Cybersecurity and Digital Asset Security Leader

## Included documents

The Version 1.0 distribution consists of:

1. Master Assessment Workbook (.xlsx)
2. Regulatory and Standards Crosswalk (.xlsx)
3. Assessment Methodology and Guidance (.docx)
4. Start Here Guide (.docx)
5. Complete Framework package (.zip)

## Baseline

- 109 core technical controls across 16 domains
- 15 core attack-path scenarios
- 16 incident-based test cases
- 11 incident records
- 22 optional supplemental controls
- 10 supplemental attack-path scenarios

Optional supplemental controls and supplemental scenarios do not change the 109-control core baseline.

## Scope note

This is a technical security assessment aid. It is not a regulatory standard, certification scheme, legal opinion or regulatory compliance conclusion. Regulatory applicability and mapping must be evaluated for the assessed legal entity, jurisdiction, licence, activities and services.
