# Contributing

Feedback and improvement suggestions are welcome.

- Open an issue for factual corrections, clarity improvements or proposed enhancements.
- Use a pull request for proposed text or documentation changes.
- Explain the security rationale and affected framework section or control ID.
- Do not silently change core control identifiers or baseline counts.
- Distinguish proposed changes from accepted framework content.
- Do not include confidential information, credentials, private keys, customer information or sensitive exploit details.

Contributions do not automatically become part of an official release. The maintainer will review and identify accepted changes in a subsequent version.
